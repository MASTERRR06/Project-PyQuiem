# 🐍 Py-Quiem

### *Python, one concept at a time.*

**Py-Quiem** is a growing collection of Python programs, exercises, experiments, and **Data Structures & Algorithms** examples built as a learning resource for students.

The name **Py-Quiem** is a play on **Python + Requiem**, inspired by *RE:Requiem*.

---

## 📚 What's Inside?

* 🐍 Python Fundamentals
* 🧩 Functions & OOP
* 🔢 NumPy
* 🌳 Data Structures & Algorithms
* 🧠 Practice & Challenge Problems

This isn't a production project — it's a **learning repository**. Read the code, run it, experiment with it, break things, fix them, and learn along the way.

> **Don't just run the code. Understand it.**

---

## 🚧 Work in Progress

Py-Quiem is **actively being developed**.

More concepts, programs, exercises, and learning material will be added as it grows.

**The journey is part of the repository.**
